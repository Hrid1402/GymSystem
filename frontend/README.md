# Frontend

1. Ubícate en la carpeta frontend y ejecuta:

```bash
npm install
```

2. Ejecuta el siguiente comando:

```bash
npm run dev
```

3. La terminal te dará una dirección local parecida a esta:

```text
http://localhost:5173/
```

Presiona **Ctrl + clic** en ese enlace (o cópialo y pégalo en tu navegador Chrome).
